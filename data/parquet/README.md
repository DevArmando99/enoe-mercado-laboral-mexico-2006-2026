# Parquet

Los archivos Parquet no se versionan en GitHub. La descarga de Mega conserva dos objetivos distintos:

- `historical/`: base concatenada lista para el análisis exploratorio.
- Otros directorios de la descarga: productos por trimestre e intermedios para reconstruir el pipeline completo.

El cuaderno exploratorio utiliza únicamente el Parquet histórico indicado en el manifiesto.
